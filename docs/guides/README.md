# Sentinel Task Guides

Start with [Install and Quick Start](../quick-start.md) and get one reply before using a guide below. Each guide targets one outcome; linked reference pages hold the complete option tables and edge cases.

You can ask Sentinel to guide your next task using the built-in `nanobot-document` skill, or read a guide yourself. See [Continue with Sentinel](../quick-start.md#continue-with-sentinel) for availability and examples. Each task guide describes its starting requirements, setup steps, and how to check the result; use the parts that match your current instance.
